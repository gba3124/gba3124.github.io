Privacy Policy

WordKit does not collect, store, transmit, or sell any personal data.

Last updated: 21 July 2026

There are no analytics, no tracking, no accounts, and no servers.

Everything WordKit does happens locally in your browser. Counting, fee calculation, width and punctuation fixing, and PDF reflow are pure text transforms that run in the page — nothing is uploaded, and there is no network request anywhere in the extension.

Your text

Text reaches WordKit two ways, and neither leaves your device:

  • You paste it into the panel’s text box.
  • You select it on a page. While the panel is open, WordKit watches the selection so it can show the count and fee as you select — it does not wait for you to press a button. That text is handed to the panel, which is part of the same extension running in the same browser, and nowhere else. Selections are ignored while the panel is closed, and anything over 200,000 characters is skipped.

WordKit keeps no history. Nothing you count is written to storage.

Permissions

  • activeTab — reads the page only when you invoke WordKit (toolbar button or keyboard shortcut), so it can see the text you select.
  • scripting — injects the panel into that tab when you open it.
  • storage — remembers your own settings. chrome.storage.sync holds preferences (charge unit, currency, rate, theme, and which width, punctuation and reflow fixes to apply); chrome.storage.local holds the panel’s on-screen position and a counter behind the “leave a review” prompt. The developer has no access to either.

WordKit requests no host permissions and declares no content script. The panel is injected under activeTab, which Chrome grants only at the moment you click — so the extension has no standing access to any site you visit, and does nothing at all on pages where you have not opened it.

Network

There is no network request in WordKit. Its translations and other resources are read from files inside the extension package with chrome.runtime.getURL(), which never touches the network.

The only external address anywhere in the extension is the Chrome Web Store review page, opened only if you click the “leave a review” link yourself.

Data use

For the Chrome Web Store’s data-use declarations, WordKit declares that it does not collect or use any of the listed user-data categories, and it meets all three certifications: no sale of data to third parties, no use for purposes unrelated to the single purpose, and no use to determine creditworthiness or for lending.

Changes

If this policy ever changes, the revision date above changes with it. Any change that affects what the extension does with your data will ship alongside the extension update that introduces it.
